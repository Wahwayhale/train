# 上海地铁驾驶模拟器

一个纯网页的 3D 驾驶游戏 —— 真实上海地铁 20 条线路、真实线形与车辆物理、真实报站音频（1 号线全程原声）。

## 怎么玩（两种方式，任选其一）

**方式 A：直接双击打开（最简单）**
解压后双击 `index.html` —— 用 Chrome 或 Edge 打开就能玩，不需要安装任何东西、不需要联网。

**方式 B：本地服务器（如果你电脑上有 Node.js）**
解压后在该目录运行：
```
node serve.js
```
然后浏览器打开 http://127.0.0.1:8787/

> 强烈推荐 **Chrome / Edge**。首次进入需要点一下页面（浏览器要求用户先点一下才允许出声）。

## 操作

| 键位 | 作用 |
|---|---|
| ↑ / ↓ | 牵引 / 制动级位 |
| D | 发车确认（车门开着也能按，自动排队关门） |
| O / C | 开门 / 关门 |
| E | 紧急制动 |
| R | 缓解 EB |
| H / 回车 | 鸣笛 |
| V | 切换视角（驾驶室 / 车尾 / 站台 / 对向） |
| 空格 / Esc | 暂停 |
| 鼠标拖拽画面 | 环视驾驶室 |
| ← / →、PgUp / PgDn | 转头 / 俯仰 |
| Home | 视线回中 |

## 提示

- 首页底部有构建号（日期时间），右上角时钟旁有实时帧率与帧 CPU 耗时。
- 1 号线（莘庄→富锦路）是**真实报站原声**；其余线路用系统语音播报。
- 想要最佳体验，用 Chrome/Edge、独显、60Hz 以上刷新率。
